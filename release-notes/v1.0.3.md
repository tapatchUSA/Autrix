**Autrix 1.0.3** for Windows 10/11 (x64) · Free for personal use

### What's new

- Exact capture — the recorder now records every button and key RELEASE, not just presses, so click-and-drags and held keys reproduce exactly instead of collapsing into single taps
- Overlapping input is preserved — hold a mouse button and move along a path, or hold a key while turning, clicking and jumping, and playback replays it all with millisecond timing (set it up right and it can run a full game parkour route)
- New raw down/up actions (M↓ / M↑ / K↓ / K↑) appear in the editor for real holds and drags; simple taps still fold back into the tidy Click / Key rows
- Stuck-key safety — every button and key held during playback auto-releases when you hit Stop, when a loop ends, or if a recording ended mid-hold, so nothing stays pressed in a game
- Exact replay uses real hardware scancodes so fullscreen games register the held inputs
