**Autrix 1.0.1** for Windows 10/11 (x64) · Free for personal use

### What's new

- Hotkeys now work when Autrix is minimised or another app is focused — global low-level hook sees every keystroke
- Auto-clicker and macro engine run on dedicated background threads — playback continues while minimised
- Live CPS counter shows real-time clicks/sec while the clicker is running
- Unlimited-throughput mode (0 ms interval) with burst-fire SendInput batching
- Inline action editor — click any row to edit X / Y / wait / text; Select Position overlay picks coordinates with one click
- Type-text action added; consecutive moves group into expandable sequences with per-point editing
- Multi-select actions (shift / ctrl / drag) with bulk delete
- Macro playback speed slider — 10% to 1000% scaling on wait durations
- Multiple named custom theme profiles, plus two new presets: MIDNIGHT and ROSE
- Import / Export profiles as JSON
