**Autrix 1.0.2** for Windows 10/11 (x64) · Free for personal use

### What's new

- Hold action — press a mouse button down for an exact duration, then release; chains with Move for positioned drag-and-drop / charge shots
- Recording precision modes — Precise / Basic / Least / Custom; Custom exposes min-move distance, drop-wait threshold, and wait-round granularity
- Recording timing is now sub-ms accurate (was dropping waits under 10 ms; now rounds to nearest ms)
- Recording auto-stops at 100k actions with a log warning instead of bricking the UI
- Keyboard auto-repeat is suppressed during recording — pressing 'L' records as one L, not LLLLL
- Continue From Last Recording (default ON) — appends new sessions to the existing action list instead of overwriting
- Unicode Type action — uses KEYEVENTF_UNICODE so emoji and any keyboard layout's symbols all type correctly
- Global click-anywhere coordinate picker — works on any window now, not just Autrix's viewport
- Status popup — borderless translucent overlay with AC / Macro / Recording lines, theme-driven colors, fade-in/out, customizable position + size
- System tray (opt-in) — minimize to tray on close with Open / Quit right-click menu
- Panic stop (opt-in) — bind any key + configurable hold duration; force-kills every hotkey-driven thing at once
- Hotkey conflict auto-resolves — binding a key already used elsewhere moves it to the new slot instead of refusing
- Multi-monitor coordinate fix — pick / move / click actions now work across the full virtual desktop
- Lock-free atomic CPS counter, Arc-shared macro action list, lower contention across UI / engine threads
- Log Detail modes (Precise / Basic / Least / Custom) — quiet down the log to just what you care about
- Custom values accept decimal seconds — popup auto-hide and panic-stop hold can be set to 0.2s, 1.5s, etc.
- Each page opens scrolled to the top; visible scroll bars hidden everywhere except the macro action list
- Selection is outline-only — no more wall of blue when drag-selecting a long range
- Status popup has hard size cap (800×500) so a runaway resize can't lock you out of the main window
- Tray menu is now real Win32 — Open / Quit work from any state, including a fully hidden window
